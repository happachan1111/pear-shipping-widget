# ホームの直近のお知らせ（ui29）

## 表示条件

- 日本時間の今日を基準に、`開始日 <= 今日+7日` かつ `終了日 >= 今日`。終了日なしは当日限り。開始7日前から終了日までを含み、終了済みは翌日から消える。
- 対象は運営カレンダーと同じ通常／母の日／父の日／敬老の日／バレンタイン／ホワイトデーの予定。
- `/orders/data` の保存済み予定と `portal/calendar-seeds.json` を統合。同一IDは保存済みを優先し、`portal_schedule_exclusion` の sourceId は除外する。
- 日付・イベント・予定名順で表示。件数の上限による切り捨てはしない。

## 操作

- 約5秒間隔で切り替え。前／次・再生／一時停止。マウス・フォーカス・一覧を読んでいる間、別画面や非表示タブでは自動切り替え停止。OSの動きを減らす設定も尊重する。
- 押すと読み取り専用の一覧ダイアログ。各予定を展開して備考を確認。運営カレンダーへのリンクあり。
- ホーム表示中は約1分ごと、ホームへの復帰・フォーカス・表示復帰・明示更新でも再取得。取得中の多重リクエストは抑制する。
- 読み取りだけで保存・削除APIは呼び出さない。

## エラーと検証

- 10秒のタイムアウト、GETだけ最大2回の取得。ホームの他機能を止めず、欄内で失敗・前回取得データ・再試行を案内する。
- 1440／390／320pxで7日・8日境界、当日、終了済み、期間中、取込の上書き・除外、5秒切り替え、停止、手動切り替え、一覧、備考展開、更新、空状態、1件、動きを減らす設定、通信失敗からの再試行を模擬APIで検証。
- HTMLを含むタイトルも文字として表示し、入力を実行しない。元データの変更・書き込みがないことを確認する。

## ui30 表示調整

PCは高さ約60pxの横長の帯、スマートフォンは見出し・操作と予定の2段に圧縮。説明文は読み上げ用に残し、取引先と備考は一覧で確認する。自動切り替え・表示条件・一覧・停止等の動作は変更しない。
