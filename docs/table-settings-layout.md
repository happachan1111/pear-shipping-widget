# 長期休暇の「表の設定」（ui35）

「表の設定」のsummaryは開閉しても112×44pxのまま。PCは年度・予定表の右、スマートフォンはその下に配置。展開するのは下側の設定内容だけ。

内容を2つに整理：
- 期間・取引先・年度（既存の期間変更・取引先追加・年度追加）
- 範囲・色・文字の編集（選択表示・範囲の終点・色コピー／貼り付け・出荷不可／色を消す・セル編集・操作結果）

元の操作要素を移すだけで、ID・イベントハンドラ・選択・コピー内容・保存処理を維持。選択しただけではトグルを勝手に開かない。設定を開いてから操作する。未選択では編集ボタンを無効にして表示し、操作前の説明を確認できるようにする。

色操作のエラー時は設定を開いてメッセージを見せる。保存／更新／未保存・保存済み表示は従来どおり画面下。保存結果の詳細文は設定内に表示する。共有データ・印刷レイアウトは変更しない。
