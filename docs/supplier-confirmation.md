# 取引先の回答確定と行ロック（ui36）

長期休暇の出荷予定の取引先名の左に「未確定／確定」トグルを表示。確定は即時にローカル反映、解除は確認後に反映する。ui40以降はどちらも約900ms後の自動保存で共有し、他端末は更新・再読み込みで取得する。年度・地域・予定表の既存レコード単位で保存する。

## 保存形式と互換性

`plan.sheets[0].cells[row][0].supplierConfirmed === true` を任意の追加項目として使用。既存の値・色・備考・表識別子・旧シートは変更しない。項目がなければ未確定。入力文字や取引先名から確定を推定しない。

行そのものに紐づくため、途中挿入で別の取引先にずれない。新規行の複製時はフラグを削除。新年度も未確定にする。期間が変わると回答対象日が変わるため、確認後に既存確定をリセットする（取消時は期間・確定とも変更しない）。

## 保護範囲

- 取引先名・日付の文字／色・備考の編集をロック。
- 備考は確定後も表示できる。編集ボタンは出さない。
- 日付クリック・ダブルクリック・Enter・既存セル編集画面の保存直前でもチェック。
- 色のコピー／貼り付け・出荷不可・色を消すは確定行を含む範囲を全体停止し、一部だけ変更しない。Ctrl/⌘+Vでも同じチェック。
- 結合セルが確定行にかかる場合も保護。取引先名が縦結合された場合は全構成行をまとめて確定／解除。
- 編集中の表示、保存・未保存表示、既存競合検知、バックアップ、A4横の印刷は従来どおり。印刷に状態用の追加列は設けない。

これは公開アプリの誤操作防止UIで、権限管理やサーバーでの書き込み禁止ではない。更新前の旧クライアントや直接APIによる編集を禁止する機能として扱わない。
