# ホームの入口（ui33）

ホームは細長い「直近のお知らせ」と4つの入口に整理。

- 運営カレンダー：直接開く。
- 長期休暇の出荷予定：山陰／沖縄を選択。従来の地域別URLへ移動し、年度・予定表は既存画面で切り替える。
- 季節イベント：7つのイベントを選択。
- 個口数：山陰／沖縄を選択。

左メニュー・既存URL・各機能・保存先は変更しない。選択画面を開く操作ではデータの変更・保存は行わない。
選択はネイティブdialog。閉じる／Escapeで元の入口へ戻る。選択後・戻る操作で画面を切り替えたときは閉じる。
運営カレンダーを最上段に横幅いっぱいで表示。PCはその下に3つの入口を横並び、スマートフォンは縦並び。小さい高さや文字拡大時は内容を切り捨てず、ホーム内の縦スクロールを許可。
お知らせの自動切替・一覧、サポートメニューと未読表示は維持する。
