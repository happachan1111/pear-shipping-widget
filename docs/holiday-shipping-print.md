# 長期休暇の出荷予定の印刷（ui27）

- `portal/holiday-shipping-print.js` と同CSSが印刷専用の表を作成。画面の週分割や編集UIは変更しない。
- 「印刷」→ 山陰1枚／沖縄1枚／両地域2枚。A4横向き・余白8mm、地域ごとに改ページ。全期間・空欄ではない取引先・出荷不可の色を印刷する。備考欄は印刷しないが保存内容は維持する。
- 内容の高さ・幅を実測し、各地域が1枚に収まるよう縮小。行数が増えると文字も小さくなる。
- `shippingPrint.getPlans()` は現在の下書き、保存済み地域別表、年度別資料のコピーを取得するだけ。保存・地域切替・行削除は行わない。
- 未保存の現在の地域も印刷可能で、用紙に未保存と表示。資料のない過年度の地域は選択不可。未入力の他地域は初期表と明示する。
- 印刷時は固定フッター・サポート・操作ボタン・画面用余白を非表示にする。備考欄は印刷専用表から省略。
- ブラウザーの背景印刷を有効にすると色を維持する。出荷不可は背景色だけで表示し、印刷専用の記号は追加しない。保存値は変更しない。
- PCとスマートフォン幅 × GW／お盆／年末年始 × 山陰／沖縄／両地域の18PDFを生成し、A4横向きで1／1／2ページであることを検証。模擬APIで保存呼出しが発生しないこと、元の表が変更されないことも比較する。
