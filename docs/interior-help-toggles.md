# ツール内の説明整理（ui34）

共通表示は `shared/page-help.js` / `.css`。補足はネイティブdetailsで初期状態は閉じる。

対象：
- 運営カレンダー：既存の区分説明に元データに関する補足を集約。「使い方・区分の見方」。
- 個口数：「上限の見方」。上部の説明と共有保存の説明を短くする。削除確認は従来どおり。
- 季節イベント（母の日〜ホワイトデー）：予測・カード・伝票の説明。予測／カードの見出し直下の説明と、表の手前の入力説明を同じトグルへまとめる。
- 梨・カニ締切：見出し下の操作のヒント。最新のお知らせは対象外。
- 長期休暇：「使い方・補足」を表の見方／色と文字の編集／表の設定／保存・印刷の4項目に整理。バックアップボタンは保持。

対象外：保存・削除・追加ボタン、入力フォーム、件数や予定、ユーザーが入力したメモ・備考・コメント、通信・検証エラー、未保存状態、検索キーの必須注意、最新のお知らせ。汎用 `.hint` / `.note` セレクタでまとめて隠さない。

既存ノードを移すだけでID・内容更新先・イベントハンドラを維持。共通モジュールは通信・書き込みをしない。動的な予測の再描画には限定的なObserverで対応し、二重トグルを作らず開閉状態を維持する。既に簡潔な発注・出荷件数やせり情報の画面は変更しない。

既存の共有データ・保存処理・リージョン・印刷・バックアップの仕様は変更しない。
